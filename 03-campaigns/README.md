# 03-campaigns

One subfolder per campaign. This is where most of the volume will end up.

## Structure

    03-campaigns/
      2026-08-preowned/
        copy.md
        graphics/
        specs.md
      2026-09-labor-day/

Date-first folder names sort themselves chronologically. That is the whole trick.

## What belongs in a campaign folder

- copy.md with headlines, body copy, and disclaimers.
- graphics/ with the finished exports actually used.
- specs.md with sizes, placements, run dates, and where it ran.

When a campaign is done and cold, move the folder to 99-archive.
