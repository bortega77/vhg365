# vhg365

Design and brand asset storage for Brian Ortega. One place for the visual stuff
so it stops living in six different folders named final_v3_REAL_final.

## What goes where

| Folder | What lives in it |
|---|---|
| 01-logos | Logo files, SVG and PNG. Master versions, not one-offs. |
| 02-brand | Colors, fonts, brand guidelines, anything that defines the look. |
| 03-campaigns | One subfolder per campaign. Copy, graphics, specs. |
| 04-mockups | HTML mockups, landing page drafts, layout tests. |
| 05-photos | Source photography and stills. |
| 99-archive | Dead stuff you are not ready to delete yet. |

## Naming rules

Keep it boring and it stays findable:

    2026-08-preowned-billboard-v1.png
    YYYY-MM-campaign-name-asset.ext

Lowercase. Hyphens instead of spaces. No FINAL, no FINALfinal.

## Size limits

Browser uploads cap at 25 MB per file. GitHub warns over 50 MB and hard-blocks
at 100 MB. Raw video and giant PSDs do not belong here. Link to those instead.
