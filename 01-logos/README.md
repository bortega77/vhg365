# 01-logos

Master logo files only. If it is a one-off treatment for a single ad, it belongs
in the campaign folder instead.

## What to put here

- SVG for anything vector. Scales forever, tiny file, works everywhere.
- PNG with transparent background for web and email use.
- One version per color treatment: full color, all white, all black.

## Naming

    vhg-logo-primary.svg
    vhg-logo-white.png
    vhg-logo-stacked-black.svg

Say what it is, not what version of your afternoon it was.
