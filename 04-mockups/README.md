# 04-mockups

HTML mockups, landing page drafts, layout tests. Anything that is a design
expressed as code rather than as an image.

## Note on live previews

GitHub shows the raw code for HTML files instead of rendering them. To see a
mockup as an actual page, turn on GitHub Pages in Settings and files here
become viewable at a real URL.

## Naming

    2026-08-preowned-landing.html
    giveaway-entry-page-v2.html

Keep each mockup self-contained: CSS and JS inside the single HTML file. It
means one file to move, one file to send, nothing to break.
