# 05-photos

Source photography and stills you actually reuse. Lot shots, staff headshots,
building exteriors, product stills.

## Keep it lean

This is the folder most likely to get out of hand. Two rules:

- Web-sized JPG or PNG only. Under 25 MB per file, ideally way under.
- If you would not reach for it again, it does not go here.

Raw camera files and full-resolution originals belong in cloud storage, not in
a git repo. Git keeps every version of every file forever, which is great for
text and brutal for a 60 MB photo you replaced four times.
